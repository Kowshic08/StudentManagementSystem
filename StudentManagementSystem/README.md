# Student Management System

## Project Description

A simple Student Management System developed using ASP.NET Web Forms and ADO.NET.

## Features

- Admin Login
- Add Student
- View Student List
- Edit Student Details
- Delete Student Details
- Required Field Validation
- Age Validation
- Email Validation

## Technologies Used

- ASP.NET Web Forms
- C#
- ADO.NET
- SQL Server
- HTML
- CSS

## Database

Database: StudentManagementDB

Tables:
- Users
- Students

## Student Details

- Student ID
- Name
- Age
- Class
- Email
